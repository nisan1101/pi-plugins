# pi-plugins

Personal [Pi](https://pi.dev) extensions installed directly from GitHub.

## Plugins

- [pi-timer](./packages/pi-timer/) — set a timer that ends the current run and wakes a later agent turn to revisit asynchronous work.
- [pi-qq](./packages/pi-qq/) — ask a one-off question with full context without saving it to the session.
- [pi-subagents](./packages/pi-subagents/) — delegate fresh-context work to in-process background subagents.
- [pi-ask-web](./packages/pi-ask-web/) — consult a remote web librarian for current, source-backed answers.

## Install

```bash
pi install https://github.com/nisan1101/pi-plugins
```

This installs all four extensions.
